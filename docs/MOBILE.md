# Локальные мобильные приложения

У приложения одна React-кодовая база и один Spring Boot backend. В `android/` создан Android-проект, в `ios/` — Xcode-проект. Генерация Capacitor выполнена локально; APK/IPA не собраны и не протестированы на устройствах, поскольку Android SDK и Xcode в этой Windows-среде отсутствуют.

## Web и PWA

Запустите `start.cmd`, откройте `http://localhost:5173`. На компьютере можно установить PWA из меню браузера. Файлы и данные аккаунта остаются на локальном сервере. Сервис-воркер хранит только экран отсутствия связи и иконки: новости, сессии, письма и API-ответы не кэшируются.

## Android

Нужны Android Studio, SDK 36 и JDK, поддержанный установленным Android Gradle Plugin (стандартный проект Capacitor использует JDK 21). Backend при этом работает на Java 25. Системный JDK проекта Spring менять ради Android не требуется.

1. Запустить `start.cmd` на компьютере.
2. Подключить эмулятор или USB-устройство с разрешённой отладкой.
3. В терминале Android SDK выполнить `adb reverse tcp:5173 tcp:5173`.
4. Выполнить `pnpm mobile:sync`, затем `pnpm mobile:android` и запустить приложение через Android Studio.

Оболочка открывает локальный frontend через перенаправленный порт. API проходит через Vite proxy на локальный Spring, поэтому не требуется открывать backend/базу в локальную сеть. Подключение по Wi-Fi в этом режиме не настроено. `cleartext` в конфигурации разрешён только для этой локальной HTTP-разработки.

## iOS

Требуются macOS и Xcode. Исходники оболочки находятся в `ios/App/`. На Mac сначала нужно запустить тот же backend/frontend, выполнить `pnpm mobile:sync` и открыть `pnpm mobile:ios`. iOS Simulator использует localhost своего Mac. Windows-сервер не является localhost iPhone/симулятора другого компьютера.

Текущие `start.cmd` и переносимые инструменты предназначены для Windows. На Mac запустите Spring Boot через Maven/Java 25 с локальной PostgreSQL и указанными в README переменными окружения, frontend — `pnpm dev`. Для проверки на физическом iPhone потребуется отдельно согласованная локальная адресация и настройки ATS/подписи. Никаких учётных записей разработчика, подписей и публикаций в магазинах в проект не добавлялось.

## Конфигурация

`capacitor.config.ts` намеренно указывает только на `http://localhost:5173`. Это локальная оболочка; самостоятельная работа APK/IPA без компьютера-сервера не заявляется. Для будущей удалённой версии потребуются HTTPS API, новая конфигурация авторизации и отдельная проверка на устройствах.
