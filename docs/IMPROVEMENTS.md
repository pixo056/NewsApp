# Улучшения NewsApp

Изменения выполнены в отдельной ветке `improvements/reliability-and-views` от исходного коммита `1099d09`. Сохранены React/TypeScript, Java 25/Spring Boot, PostgreSQL и существующие правила модерации.

## Исправленные проблемы

- **Просмотры:** повторное открытие или повторный POST раньше каждый раз увеличивали счётчик. Теперь одна новость учитывает аккаунт не чаще раза за 24 часа, в том числе в разных браузерах. Для гостя окно действует в пределах серверной сессии. Одновременные запросы учитываются атомарно. Скрытые/неопубликованные новости возвращают 404. Миграция V2 сохраняет существующие счётчики; IP и исходные идентификаторы сессий не сохраняются. Новая гостевая сессия может дать новый просмотр: абсолютная защита от накрутки не заявляется.
- **Лимиты через Wi-Fi:** сервер раньше видел общий адрес Vite и объединял попытки входа/регистрации/восстановления всех посетителей. Proxy теперь передаёт проверенный адрес socket-соединения; входящие пользовательские маркеры заменяются. Backend доверяет маркеру только с loopback. Ограничение тестовой почты остаётся отдельным.
- **Параллельные изменения:** при изменении лимита или официального статуса паблика ожидающий запрос мог использовать устаревшие сведения. Проверка и блокировка строки теперь согласованы для отправки новости и редактирования паблика.
- **Подписки:** открытая лента подписок раньше не обновлялась после подписки в правой колонке. Теперь она перезагружается и сбрасывает курсор без ручного обновления страницы.
- **Форма новости:** ограничения заголовка и текста проверяются до отправки по Unicode code points, как на сервере. Заголовок из 150 emoji вводится полностью. Ошибки выводятся возле полей; источник проверяется как HTTP(S)-ссылка. Пустые/слишком большие файлы и недопустимые сочетания вложений отклоняются до загрузки.
- **Видео:** вместо 60 секунд/100 МиБ действуют присланные требования — 3 минуты/200 МиБ, до 1080p, MP4/MOV. Согласованы форма, multipart-ограничения и FFmpeg; допустимое видео больше не обрезается до минуты. Фото остаются до 10 МиБ, до четырёх на новость.
- **Ошибки связи:** недоступный или некорректно отвечающий CSRF endpoint даёт понятное сообщение при входе, изменениях и загрузке файлов.
- **Запуск:** прерванная загрузка инструмента больше не оставляет повреждённый архив, блокирующий дальнейшую установку. Используются временный файл, контрольная сумма, ограниченные повторные попытки и атомарная замена. Браузер открывается после проверки готовности frontend. Проверена совместимость вспомогательных скриптов с Windows PowerShell 5.1 и PowerShell 7.

## Проверки

Все 46 автоматических проверок прошли: 24 backend, 8 frontend, 4 сетевые и 10 проверок запуска. Backend использовал настоящую отдельную PostgreSQL-базу `newsapp_test`. Видеотест создал ролик на 180 секунд и проверил длительность преобразованного файла; ролик на 181 секунду отклонён. Тест размера отклоняет 200 МиБ + 1 байт без выделения большого массива.

Два теста конкуренции удерживают реальную блокировку PostgreSQL и проверяют применение новых прав/лимитов после её освобождения. Просмотры проверены повторно, параллельно, между сессиями одного аккаунта и после истечения окна.

Прошли production-сборка frontend, форматирование, проверка пробелов и полный HTTP-сценарий через Vite: регистрация, CSRF, подтверждение, вход, фото, модерация паблика, просмотры, правки, подписки, сохранения, реакции, поиск, жалоба, скрытие, восстановление пароля и завершение старой сессии. Обычный запуск `start.cmd --no-open` проверен с ответами frontend и `/api/health`.

В браузере отдельно проверены 150 emoji, ошибки формы, успешная отправка на модерацию и появление новости в открытой ленте подписок сразу после подписки в правой колонке. На узком экране горизонтального переполнения не обнаружено.

Команды проверки:

```powershell
pnpm build
pnpm format:check
pnpm test:network
pnpm test:frontend
pnpm test:launcher
.\scripts\test-backend.ps1
node scripts/smoke-local.mjs
```

Физические Android/iPhone, подключение телефона по Wi-Fi, APK/IPA, установка PWA и настоящая отправка почты в этой работе не проверялись. Комментарии и другие новые социальные функции не добавлялись. Приложение остаётся локальным; публичная публикация исходников не размещает работающий сервис в интернете.
