# Состояние требований

Реализован локальный рабочий web-сервис с backend, PostgreSQL и файловыми медиа. Стартовые материалы/паблики демонстрационные; пользовательские данные сохраняются. Стек сохраняет Java 25 и локальный режим. Все новости и их правки, включая материалы обычных пабликов, одобряет только администрация платформы.

## Принятые лимиты

Материал в паблик предлагают со страницы самого паблика: «Предложить новость» открывает форму с закреплённым получателем. Выбора другого паблика в редакторе нет. Общая форма `/create` предназначена для личных публикаций; из неё можно перейти в каталог пабликов. После входа гость возвращается к предложению в выбранный паблик. Правила модерации этим изменением не меняются.

Заголовок 10–150, текст 50–10 000 Unicode code points с пробелами. С видео текст необязателен. До четырёх фото по 10 МиБ либо одно MP4/MOV до 200 МиБ, 3 минут и 1080p. Размеры файлов измеряются в МиБ (200 × 1024 × 1024 байт); ограничения согласованы на сервере и в форме. GIF и смешивание фото с видео не реализованы.

Пабликом управляет один создатель. Публичный официальный статус назначает только ADMIN. Владелец меняет название и описание своего обычного паблика, а в CMS видит и редактирует только свои нескрытые новости в нём. Одобрение, отклонение, рассмотрение жалоб, скрытие и восстановление доступны только ADMIN. Создание паблика пока не проходит отдельную модерацию. Автоматической публикации новости при отправке нет.

Реакции доступны зарегистрированным читателям: 👍 «Нравится», 🎉 «Поздравляю», 💡 «Интересно» и ❤️ «Поддерживаю». У аккаунта одна реакция на новость; её можно заменить или снять. Гости видят счётчики. Миграция V4 сохраняет существующие лайки как `like`.

## Платформы и границы

Web/PWA доступны локально. Android/iOS — исходники локальных Capacitor-оболочек, без проверенной сборки APK/IPA и без публикации. См. MOBILE.md. Внешняя SMTP-почта/S3 намеренно не подключены: данные и тестовые письма остаются на компьютере. Реальную проверку принадлежности к университету/SSO, дополнительных редакторов, push-уведомления, комментарии, личные сообщения и AI-модерацию не добавляли.

PWA кэширует экран отсутствия связи, а не новости/закрытые данные. Хранение неопубликованных/исторических вложений остаётся локальным; связанные с ревизиями медиа не удаляются при изменении текста.

## Панель CMS

Для редакции подключена готовая свободная основа React-admin поверх существующего Spring Boot API. Новости, модерация, паблики, пользователи, жалобы и история доступны без работы с кодом. Сервер ограничивает панель владельца его обычными пабликами и собственными нескрытыми новостями в них. Административные решения и работа с пользователями доступны ADMIN. Подробности — [CMS.md](CMS.md), сравнение с презентацией кейса — [CASE_REVIEW.md](CASE_REVIEW.md).
