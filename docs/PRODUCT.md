# Состояние требований

Реализован локальный рабочий web-сервис с backend, PostgreSQL и файловыми медиа. Стартовые материалы/паблики демонстрационные; пользовательские данные сохраняются. Режим работы и права уточнены пользователем: Java 25, администрация для официальных пабликов, создатель для обычных, без публикации наружу.

| 1, 19 — регистрация и гостевое чтение  | Реальные аккаунты, сессии, открытая общая лента                                                                 |

## Принятые лимиты

Заголовок 10–150, текст 50–10 000 Unicode code points с пробелами. С видео текст необязателен. До четырёх фото по 10 МиБ либо одно MP4/MOV до 100 МиБ, 60 секунд и 1080p. Это сокращённые лимиты из предложенного плана, принятого к реализации; первоначальные 200 МБ/3 минуты не используются. GIF и смешивание фото с видео не реализованы.

Пабликом управляет один создатель. Публичный официальный статус назначает только ADMIN. Сам владелец обычного паблика может одобрять и собственные предложения, так как выполняет роль его модератора. Автоматической публикации при отправке нет.

## Платформы и границы

Web/PWA доступны локально. Android/iOS — исходники локальных Capacitor-оболочек, без проверенной сборки APK/IPA и без публикации. См. MOBILE.md. Внешняя SMTP-почта/S3 намеренно не подключены: данные и тестовые письма остаются на компьютере. Реальную проверку принадлежности к университету/SSO, дополнительных редакторов, push-уведомления, комментарии, личные сообщения и AI-модерацию не добавляли.

PWA кэширует экран отсутствия связи, а не новости/закрытые данные. Хранение неопубликованных/исторических вложений остаётся локальным; связанные с ревизиями медиа не удаляются при изменении текста.
